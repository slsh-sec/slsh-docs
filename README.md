# slsh-docs

Public policies, terms of service, and documentation for [slsh.jp](https://slsh.jp).

本リポジトリでは、[slsh.jp](https://slsh.jp) における各種利用規約・ドキュメントの改定履歴を管理しています。

---

## 変更履歴の確認方法

規約がいつ、どこが変更されたかを確認する方法は以下の2通りあります。

### 1. 最新の規約を確認する
以下のリンクから、現在最新の規約を閲覧できます。
- [セキュリティ運用保守](terms/terms-maintenance.md)

### 2. 過去の改定履歴・変更差分を確認する
確認したい改定日のコミットタイトルをクリックすると、変更箇所の差分が、緑色（追加行）と赤色（削除行）で視覚的に表示されます。
- [セキュリティ運用保守](https://github.com/slsh-sec/slsh-docs/commits/main/terms)
